# Environment Variables Reference

All environment variables used by nself, organized by category.

## Core Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `ENV` | `dev` | Environment: dev, staging, prod |
| `PROJECT_NAME` | (required) | Project identifier, used in container names and paths |
| `BASE_DOMAIN` | `localhost` | Base domain for all service routing |

## Database (PostgreSQL)

| Variable | Default | Description |
|----------|---------|-------------|
| `POSTGRES_PORT` | `5432` | PostgreSQL port |
| `POSTGRES_DB` | `${PROJECT_NAME}` | Database name |
| `POSTGRES_USER` | `postgres` | Database user |
| `POSTGRES_PASSWORD` | (generated) | Database password |
| `POSTGRES_EXTENSIONS` | `uuid-ossp,pgcrypto` | Comma-separated list of extensions to install |

## Hasura (GraphQL API)

| Variable | Default | Description |
|----------|---------|-------------|
| `HASURA_ROUTE` | `api.${BASE_DOMAIN}` | Hasura API subdomain |
| `HASURA_GRAPHQL_ADMIN_SECRET` | (generated) | Admin secret for Hasura console |
| `HASURA_GRAPHQL_ENABLE_CONSOLE` | `true` | Enable Hasura console UI |
| `HASURA_GRAPHQL_DEV_MODE` | `true` | Enable dev mode (verbose errors) |
| `HASURA_GRAPHQL_CORS_DOMAIN` | `*` | CORS allowed origins |
| `HASURA_GRAPHQL_ENABLE_TELEMETRY` | `false` | Hasura telemetry |
| `HASURA_GRAPHQL_ENABLED_LOG_TYPES` | `startup,http-log` | Comma-separated log types |

## Authentication (nHost Auth)

| Variable | Default | Description |
|----------|---------|-------------|
| `AUTH_ROUTE` | `auth.${BASE_DOMAIN}` | Auth service subdomain |
| `AUTH_PORT` | `4000` | Auth service internal port |
| `AUTH_JWT_SECRET` | (generated) | JWT signing secret |

## Storage (MinIO)

| Variable | Default | Description |
|----------|---------|-------------|
| `STORAGE_ROUTE` | `storage.${BASE_DOMAIN}` | Storage service subdomain |
| `MINIO_ROOT_USER` | `minioadmin` | MinIO admin user |
| `MINIO_ROOT_PASSWORD` | (generated) | MinIO admin password |

## Nginx

| Variable | Default | Description |
|----------|---------|-------------|
| `NGINX_PORT` | `80` | HTTP port |
| `NGINX_SSL_PORT` | `443` | HTTPS port |
| `SSL_ENABLED` | `false` | Enable SSL termination |

## Redis

| Variable | Default | Description |
|----------|---------|-------------|
| `REDIS_ENABLED` | `false` | Enable Redis service |
| `REDIS_PORT` | `6379` | Redis port |

## nself Admin

| Variable | Default | Description |
|----------|---------|-------------|
| `NSELF_ADMIN_ENABLED` | `false` | Enable admin companion UI |
| `NSELF_ADMIN_PORT` | `3021` | Admin UI port |
| `NSELF_ADMIN_VERSION` | `latest` | Admin Docker image version |
| `NSELF_ADMIN_DEV` | `false` | Route to host dev server instead of Docker |
| `NSELF_ADMIN_LOCAL_PATH` | (empty) | Mount local admin source for development |
| `NSELF_ADMIN_ROUTE` | `admin.${BASE_DOMAIN}` | Admin subdomain |

## Plugin System

| Variable | Default | Description |
|----------|---------|-------------|
| `NSELF_PLUGIN_DIR` | `~/.nself/plugins` | Plugin installation directory |
| `NSELF_PLUGIN_LICENSE_KEY` | (empty) | Pro plugin license key (nself_pro_ prefix) |
| `NSELF_PLUGIN_REGISTRY` | `https://plugins.nself.org` | Plugin registry URL |
| `NSELF_REGISTRY_CACHE_TTL` | `300` | Registry cache TTL in seconds |

## AI Plugin

| Variable | Default | Description |

## Monitoring

| Variable | Default | Description |
|----------|---------|-------------|
| `MONITORING_ENABLED` | `false` | Enable full monitoring stack |
| `GRAFANA_PORT` | `3000` | Grafana dashboard port |
| `PROMETHEUS_PORT` | `9090` | Prometheus port |

## Custom Services

| Variable | Default | Description |
|----------|---------|-------------|
| `CS_1_ENABLED` through `CS_10_ENABLED` | `false` | Enable custom service slot |
| `CS_1_NAME` through `CS_10_NAME` | (empty) | Custom service name |
| `CS_1_PORT` through `CS_10_PORT` | (empty) | Custom service port |
| `CS_1_TEMPLATE` through `CS_10_TEMPLATE` | (empty) | Template: express, fastapi, gin, etc. |

## Behavioral

| Variable | Default | Description |
|----------|---------|-------------|
| `AUTO_FIX` | `true` | Auto-fix common issues during start |
| `LOG_LEVEL` | `info` | Logging level: debug, info, warn, error |
| `MAILPIT_ENABLED` | `false` | Enable local email testing with Mailpit |

## Environment File Cascade

Files are loaded in order, later values override earlier:

```
.env.dev          # Team-wide dev defaults (committed)
.env.local        # Personal overrides (gitignored)
.env.staging      # Staging-specific values
.env.prod         # Production-specific values
.env.secrets      # Sensitive values (gitignored)
.env.computed     # Generated by nself build (never hand-edit)
```
